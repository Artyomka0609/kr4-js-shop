# ShopProject — контрольная работа №4

Учебный интернет-магазин наушников Sony, мышей и клавиатур Logitech. Основа проекта перенесена из [КР №1](https://github.com/Artyomka0609/kr1-html-css-shop).

## Практическая работа №15

Первым товаром для разбора была мышь Logitech M100. Объект хранит название, категорию, цену и наличие. В `js/products.js` собраны функции форматирования цены, расчёта скидки и получения статуса. Краткое описание выводится на главной странице через `textContent`. Этот способ показывает данные как обычный текст.

Откройте `index.html` и консоль браузера. Выражение `calculateFinalPrice(2500, 10)` возвращает 2250, а `createProductSummary(products[1])` выводит название, стоимость и наличие мыши.

## Практическая работа №16

В `js/data.js` находятся девять моделей в трёх категориях. У каждой модели есть артикул, цена, наличие и характеристики. `getPreparedProducts(products, "sony", "audio", "asc")` находит три модели Sony и сортирует их по возрастанию цены. Поиск игнорирует регистр и пробелы по краям. Сортировка сохраняет исходный порядок массива `products`.

На главной странице показаны число моделей, количество в наличии и средняя цена. Эти значения рассчитываются по данным каталога.
