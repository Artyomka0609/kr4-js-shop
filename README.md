# ShopProject — контрольная работа №4

Учебный интернет-магазин наушников Sony, мышей и клавиатур Logitech. Основа проекта перенесена из [КР №1](https://github.com/Artyomka0609/kr1-html-css-shop).

## Практическая работа №15

В `js/data.js` описана мышь Logitech M100. Объект хранит название, категорию, цену и наличие. В `js/products.js` собраны функции форматирования цены, расчёта скидки и получения статуса. Краткое описание выводится на главной странице через `textContent`. Этот способ показывает данные как обычный текст.

Откройте `index.html` и консоль браузера. Выражение `calculateFinalPrice(2500, 10)` возвращает 2250, а `createProductSummary(product)` выводит название, стоимость и наличие мыши.
