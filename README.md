# ShopProject — контрольная работа №4

Учебный интернет-магазин наушников Sony, мышей и клавиатур Logitech. Проект по дисциплине «Фронтенд и бэкенд разработка». Тема работы — JavaScript, DOM, события, формы и валидация.

[Открыть магазин](https://artyomka0609.github.io/kr4-js-shop/) · [Перейти в каталог](https://artyomka0609.github.io/kr4-js-shop/catalog.html)

За основу взят [собственный HTML/CSS-магазин из КР №1](https://github.com/Artyomka0609/kr1-html-css-shop). В каталоге сохранены девять моделей и их характеристики. Сайт написан на HTML, CSS и чистом JavaScript.

## Локальный запуск

Скачайте репозиторий и откройте терминал в папке с `index.html`. Запустите локальный сервер через Python 3.

```sh
python -m http.server 8000
```

Откройте [магазин на localhost](http://localhost:8000/). Также подойдёт Live Server в VS Code. Все страницы следует открывать на одном адресе и порту, чтобы они использовали общую корзину. Сборка и установка пакетов не требуются.

## Данные и каталог

Модели хранятся в массиве `products`. У каждой модели есть строковый артикул `id`, название `title`, категория `category`, цена `price` и признак наличия `isAvailable`. Также указаны изображение, описание и характеристики, а для товаров со скидкой — прежняя цена. Изображения иллюстрируют категории. Цены и наличие учебные.

При вводе запроса и изменении параметров `updateCatalog()` заново готовит список и выводит карточки. Поиск игнорирует регистр и пробелы по краям. Категория, диапазон цен и наличие применяются одновременно. Можно выбрать исходный порядок, сортировку по возрастанию или убыванию цены и по названию. Сортировка работает с копией массива. Если результатов нет, появляется сообщение и кнопка сброса. Параметры каталога сохраняются в адресной строке.

Карточки и строки таблиц создаются через `createElement`, `classList` и `append`. Текстовые данные выводятся через `textContent`. Кнопки получают артикул через `dataset`. Обработчики подключены через `addEventListener`.

## Корзина и заявки

Кнопка «В корзину» добавляет одну единицу товара. Количество и сумма пересчитываются после каждого изменения. Клавиатура Logitech K120 временно отсутствует, её заказ недоступен. Для одного товара можно открыть «Быстрый заказ». Диалог закрывается кнопкой, клавишей Escape и щелчком за пределами окна. После закрытия фокус возвращается к кнопке, с которой открывали форму.

Корзина хранится в `localStorage` под ключом `shopproject.kr4.cart.v1` в виде JSON-массива. Например, `[{"id":"m100","quantity":2}]` — две мыши Logitech M100. После чтения проверяются артикулы, наличие и количество. Цена всегда берётся из каталога. Изменения синхронизируются между вкладками. Если сохранённая запись повреждена, сайт открывает пустую корзину. Выбранная тема хранится отдельно под ключом `shopproject.theme.v1`.

В форме проверяются имя от двух символов после удаления пробелов по краям, электронная почта с доменной зоной, российский номер из 11 цифр с начальной 7 или 8 и согласие. В телефоне допускаются пробелы, скобки и дефисы. Ошибки появляются у соответствующих полей, а фокус переходит к первой ошибке. После исправления сообщение снимается. Контактные данные обрабатываются в открытой форме. После успешного оформления заказа из корзины показывается сумма и корзина очищается. Быстрый заказ и обращение через «Контакты» оформляются отдельно.

## Структура кода

| Файл | Назначение |
| --- | --- |
| `js/data.js` | Массив из девяти товаров и названия трёх категорий |
| `js/products.js` | Форматирование цены, расчёт скидки, поиск, фильтрация, сортировка и статистика |
| `js/view.js` | DOM-элементы карточек, страница модели и таблицы характеристик |
| `js/catalog.js` | Состояние фильтров, обработка событий и обновление выдачи |
| `js/cart.js` | Чтение и запись корзины, количество, сумма, состав заказа |
| `js/modal.js` | Открытие и закрытие окна заявки, выбор модели и возврат фокуса |
| `js/validation.js` | Проверка полей, сообщения об ошибках и завершение заявки |
| `js/theme.js` | Светлая и тёмная темы, меню на телефоне |
| `js/main.js` | Главная страница, действия с товарами и инициализация |
| `css/style.css`, `css/responsive.css` | Основное оформление и адаптивные правила |

В `images/` находятся иллюстрации категорий и две версии обложки WebP для разных экранов. Шрифт Manrope подключён локально из `fonts/`. [Лицензия шрифта](fonts/OFL.txt)

## Практические работы и проверка

1. **ПЗ №15**, ветка `feature/js-basics`. Подключение скриптов с `defer`, первый объект товара, форматирование цены, функции расчёта скидки, получение статуса и безопасный вывод описания.
2. **ПЗ №16**, ветка `feature/products-array`. Массив товаров, поиск по артикулу и названию, фильтрация, сортировка и расчёт средней цены. Число доступных моделей и средняя цена выведены под таблицей сравнения.
3. **ПЗ №17**, ветка `feature/dom-events`. Генерация карточек, события каталога, обработка форм и сообщения на странице. Самостоятельные доработки — корзина с синхронизацией вкладок, быстрый заказ, ссылки на отфильтрованный каталог и сохранение темы.

Откройте `catalog.html` и введите в поиске `Sony`. При сортировке по возрастанию цены останутся WH-CH520 за 5 990 ₽, WH-CH720N за 12 990 ₽ и WH-1000XM5 за 29 990 ₽. Чтобы проверить сумму, добавьте две мыши M100 и одни наушники WH-CH520. В корзине будет три единицы на 7 588 ₽. Обновите страницу, измените количество и перейдите к оформлению.

Для проверки функций откройте Console в инструментах разработчика.

```js
calculateDiscount(2500, 10)                              // 250
calculateFinalPrice(2500, 10)                            // 2250
createProductSummary(findProductById(products, 'm100'))  // название, цена и наличие
getProductTitles(getPreparedProducts(products, 'sony', 'audio', 'asc'))
countAvailableProducts(products)                         // 8
calculateAveragePrice(products)                          // 7247
```

Во вкладке Sources откройте `js/catalog.js` и поставьте точку останова в `updateCatalog()` на строке с вызовом `getPreparedProducts`. Измените поисковый запрос и проверьте список `filtered` после шага вперёд.

Все шесть страниц проверены на ширинах 360, 430, 768, 1024 и 1440 px. На телефоне меню и панель фильтров сворачиваются, таблица сравнения прокручивается внутри своего блока. В начале страницы есть ссылка пропуска к содержимому для навигации с клавиатуры.
